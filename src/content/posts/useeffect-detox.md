Год назад в нашем проекте было 214 вызовов `useEffect`. Сейчас 38. Вот три паттерна, которые я убрал первыми.

## 1. Производное состояние

Если значение вычисляется из пропсов или другого состояния, ему не нужен свой `useState` и эффект для синхронизации.

```tsx
// было
const [fullName, setFullName] = useState('');
useEffect(() => {
  setFullName(`${first} ${last}`);
}, [first, last]);

// стало
const fullName = `${first} ${last}`;
```

## 2. Реакция на событие

Аналитика после клика — часть обработчика клика, а не эффект, который следит за флагом.

```tsx
function onSubmit(form: FormData) {
  save(form);
  track('form_submitted'); // здесь, а не в useEffect
}
```

## 3. Загрузка данных

Для запросов есть библиотеки, которые уже решили кэш, гонки и повторы:

```tsx
const { data, isPending } = useQuery({
  queryKey: ['post', slug],
  queryFn: () => getPost(slug),
});
```

> Эффект нужен, когда вы синхронизируетесь с чем-то **вне** React: DOM-API, сокетом, сторонним виджетом.

Что у нас осталось в эффектах:

1. подписки на `WebSocket`;
2. интеграция с картой;
3. фокус и скролл после навигации.
