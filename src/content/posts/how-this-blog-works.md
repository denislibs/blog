Этот блог — папка с markdown-файлами. Никакой CMS и админки: пишу текст в редакторе, делаю `git push`, через минуту запись на сайте.

## Структура

```text
src/
  content/
    posts/
      perf-120fps.md
      how-this-blog-works.md
  pages/
    index.astro          # список записей
    posts/[slug].astro   # страница записи
    api/likes.ts         # счётчик лайков
public/
  images/                # картинки для записей
```

Каждый файл начинается с фронтматтера, из него собирается список на главной:

```yaml
---
title: Как устроен этот блог
date: 2026-11-18
excerpt: Короткое описание для списка
tags: [meta, astro]
---
```

## Почему не Medium

> Хочу, чтобы тексты лежали рядом с кодом и жили столько же, сколько репозиторий.

- **Контроль.** Свой домен, свой дизайн, никаких пейволов.
- **Скорость.** Статический HTML открывается мгновенно.
- **Git как история.** Каждая правка — коммит, любую можно откатить.

## Лайки

Единственная динамика на сайте. Маленький эндпоинт хранит счётчик по `slug`:

```js
export async function like(slug) {
  const res = await fetch('/api/likes', {
    method: 'POST',
    headers: { 'content-type': 'application/json' },
    body: JSON.stringify({ slug, action: 'like' }),
  });
  if (!res.ok) throw new Error('Лайк не сохранился');
  return (await res.json()).count;
}
```

Защита от накрутки простая: один лайк на браузер плюс лимит запросов с одного IP. Для личного блога хватает.
