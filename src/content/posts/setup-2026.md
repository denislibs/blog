## Терминал

- **Ghostty** — быстрый и без конфига на 300 строк.
- **fish** — автодополнение из коробки.
- **tmux** — одна сессия на проект.

## Редактор

Neovim для правок на сервере, VS Code для всего остального. Шрифт *JetBrains Mono*, 14 pt, лигатуры выключены.

## Алиасы

```bash
alias gs="git status -sb"
alias gl="git log --oneline --graph -20"
```
