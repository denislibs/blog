`rebase` пугает, потому что переписывает историю. Но если знать три команды, страх проходит.

## Перед началом

```bash
git switch feature/login
git fetch origin
git rebase origin/main
```

## Если что-то пошло не так

```bash
git rebase --abort        # вернуть всё как было
git reflog                # найти коммит до rebase
git reset --hard HEAD@{3}
```

> `reflog` помнит всё, что вы делали за последние 90 дней. Потерять коммит в git очень сложно.

## Правило

Ребейзить только свои ветки, которые ещё никто не забрал. Общую `main` — никогда.
